Запросы
Запросы — это способ прямой коммуникации с друзьями в играх. С их помощью можно приглашать и возвращать игроков, отправляя подарки, просьбы о помощи, вызовы на бой и другие уведомления. Это один из самых эффективных инструментов вовлечения. По нашей статистике, они дают до 20% всех запусков игр на мобильных устройствах и в десктопных версиях.
Друзья увидят запрос как всплывающее сообщение и в ленте уведомлений: в десктопной версии сайта и в мобильном приложении.
Требования
Отправка запросов друзьям возможна в играх, которые прошли модерацию и были опубликованы в каталоге.
В неопубликованных играх отправка запросов возможна только между администраторами игры. Это позволяет протестировать работу запросов.
Как реализовать
Вызовите событие VKWebAppShowRequestBox библиотеки VK Bridge, чтобы отправить запрос.
JavaScript
bridge.send('VKWebAppShowRequestBox', 
  {
    uid: 743784474,
    message: 'Пожалуйста, отправь мне кирку с длинной ручкой.',
    requestKey: 12345
  })
  .then( (data) => {
    if (data.success) {
      // Запрос отправлен.
      // Ключ: 
      //   console.log('Ключ переданного запроса: ', data.requestKey);
      // ... 
    }
  })
  .catch( (e) => { 
    console.log(e /* Ошибка */);
    }  
  });
В игре ВКонтакте появится окно с запросом отправки уведомления другу, идентификатор которого указан в вызове события.
Пример запроса ВКонтакте
В Одноклассниках друзей можно выбрать на этапе отправки.
Пример запроса в Одноклассниках
Если вы подключили библиотеку VK Bridge в HTML-коде страницы, то в вызове надо использовать имя объекта vkBridge вместо bridge.
Советы
•
Пользователям удобнее, когда игра показывает список друзей с кнопкой отправки напротив каждого имени.
•
Чтобы получить идентификаторы друзей, используйте запросы friends.getAppUsers или friends.get.
•
Текст запроса может быть произвольным. Мы рекомендуем использовать продуманные шаблоны, подходящие под сценарий вашей игры.
•
Если пользователь запускает игру из запроса, ВКонтакте передаёт параметр события requestKey игре как URL-параметр с именем vk_request_key. Используйте это значение, чтобы определить сценарий входа и отслеживать конверсию. Подробнее — в разделе Параметры запуска.
