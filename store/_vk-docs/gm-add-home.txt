Добавление на главный экран Android-устройства
Чтобы пользователи играли в вашу игру чаще, важно упростить её запуск. Самый простой способ старта на мобильном устройстве — нажать на иконку игры на главном экране.
Иконка игры на главном экране
Когда пользователь запускает игру в первый раз, ВКонтакте автоматически предлагает добавить её на главный экран. Если пользователь отказался, можно показать предложение позже с помощью события библиотеки VK Bridge.
Особенности использования
•
Добавить иконку игры на главный экран можно только на Android-устройствах.
•
На некоторых Android-устройствах добавление иконки может не работать, например на некоторых смартфонах Xiaomi с прошивкой MIUI.
Библиотеки ВКонтакте используют для размещения иконки на главном экране стандартные возможности Android. Если операционная система, установленная на устройстве пользователя, не обрабатывает запросы ожидаемым образом, библиотеки ВКонтакте не могут разместить иконку.
Как реализовать
Способ 1
Пользователь может добавить игру на главный экран из экшен-меню.
В игре нужно выбрать ••• → На главный экран.
Добавление игры на главный экран самостоятельно
Инструкция по добавлению иконки
После этого игра появится на главном экране.
Способ 2
1.
С помощью события VKWebAppAddToHomeScreenInfo проверьте, не добавлена ли уже игра на главный экран.
2.
Вызовите событие VKWebAppAddToHomeScreen. ВКонтакте запросит у пользователя разрешение на добавление иконки игры на главный экран. Если пользователь согласится, то увидит инструкцию для добавления.
Добавление игры на главный экран. Запрос разрешения
Пример добавления иконки на главный экран:
JavaScript
// Проверяем, добавлена ли игра на главный экран
bridge.send('VKWebAppAddToHomeScreenInfo')
  .then( (data) => {
    if (! data.is_added_to_home_screen) {    // Если не добавлена,
      bridge.send('VKWebAppAddToHomeScreen') //  то добавляем
        .then( (data) => {
          if (data.result) {
            // Игра добавлена,
            // можно выдать пользователю бонус
            // ...
          } else {
            // Игра уже добавлена
          }
        })
        .catch( (e) => {
          // Пользователь отклонил запрос или 
          // произошла ошибка
        })    
     }
   })
   .catch( (e) => { console.log('Ошибка', e); });
Если вы подключили библиотеку VK Bridge в HTML-коде страницы, в вызове надо использовать имя объекта vkBridge вместо bridge.
Советы
•
Предложите бонус за добавление игры на главный экран. Пользователи получат награду и быстрый старт, а вы — больше запусков игры.
•
Не показывайте предложение с добавлением на главный экран сразу после запуска. Это может вызвать негативную реакцию.
