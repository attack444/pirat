# Яндекс Игры — публикация «Пират 2048»

Гайд по публикации браузерной версии игры на платформе **Яндекс Игры**
(games.yandex.ru). Игра запускается в iframe на Яндексе, SDK v2 встроен хостом.

Обновлён: 2026-08-18.

## Что уже реализовано (SDK-адаптер `js/platform-sdk.js`)

| Возможность | API Яндекса | Статус |
|-------------|-------------|--------|
| Инициализация | `YaGames.init()` + `getPlayer({ scopes: false })` | ✅ |
| Загрузочный экран | `ysdk.features.LoadingAPI.setLoadingProgress/ready` | ✅ |
| Облачные сохранения | `player.setData/getData` (ключ `pirat2048`) | ✅ |
| Лидерборд | `getLeaderboards().setLeaderboardScore('pirat2048_top', ...)` | ✅ |
| Реклама interstitial | `ysdk.adv.showFullscreenAdv` | ✅ |
| Реклама rewarded | `ysdk.adv.showRewardedVideo` | ✅ |
| Поделиться | `navigator.share` / clipboard | ✅ |
| Service Worker на площадке | — | ✅ не регистрируется (только standalone-веб) |

Все методы безопасны: без SDK / без авторизации / без модерации рекламы они
возвращают `false`/пустые данные, игра продолжает работать (web-режим).

## Сборка (локально, Windows)

```bash
npm run build:yandex
# → build/yandex/  (index.html, manifest.json, sw.js, privacy-policy.html,
#   css/styles.css, icons/, js/ — 14 модулей, без тестов и мусора)

powershell -Command "Compress-Archive -Path 'D:\pirat\build\yandex\*' -DestinationPath 'D:\pirat\build\pirate-2048-yandex.zip' -Force"
# → build/pirate-2048-yandex.zip (≈90 КБ) — готов для загрузки в кабинет
```

ZIP **уже собран и актуален** (пересобран 18.08.2026 после фикса SW):
`build/pirate-2048-yandex.zip`, 90541 байт. Внутри:
- `index.html` лежит в корне (требование Яндекса);
- `js/main.js` — актуальный, с условием `platform.isWeb && sdk.host === 'web'`
  (на площадке SW не регистрируется);
- `sw.js` включён (PWA), но на Яндексе не срабатывает;
- `icons/icon-512.png` — иконка 512×512 для кабинета;
- `privacy-policy.html` — политика конфиденциальности (нужна для раздела «Конфиденциальность»).

Повторная сборка/переархивация (если меняли код):
```bash
npm run build:yandex && powershell -Command "Compress-Archive -Path 'D:\pirat\build\yandex\*' -DestinationPath 'D:\pirat\build\pirate-2048-yandex.zip' -Force"
```

## Пошаговая инструкция отправки в кабинет (детально)

> Адрес кабинета: **https://games.yandex.ru** (войти по Яндекс ID; для создания игры
> нужно подтвердить аккаунт разработчика — номер телефона).

### Шаг 1. Создать игру
1. На главной кабинета нажать **«Добавить игру»** / **«Создать игру»**.
2. Выбрать тип **«Браузерная игра»** (не «Мобильная»).
3. Указать название: **Пират 2048**.

### Шаг 2. Загрузить игровой файл (ZIP)
1. Открыть вкладку/раздел **«Игровые файлы»** (или «Архив игры»).
2. Загрузить `D:\pirat\build\pirate-2048-yandex.zip` (**90 КБ**).
3. Требование Яндекса выполнено: `index.html` в корне архива.
4. Нажать «Сохранить»/«Проверить» — кабинет распакует архив и покажет структуру.

### Шаг 3. Заполнить метаданные (страница «Основное»/«Описание»)
| Поле | Значение |
|------|----------|
| Название | Пират 2048 |
| Короткое описание | Классическая 2048 в пиратском стиле: 7 уровней, без рекламы. |
| Полное описание | то же, что в `GOOGLE_PLAY.md` (полное описание) |
| Категория | Головоломки (Puzzle) |
| Теги | 2048, головоломка, пират, числа, пазл |
| Язык | Русский |
| Возрастной рейтинг | 3+ (без насилия, азарта и покупок) |
| Платформа | Браузер (desktop + mobile) |
| Ссылка на политику конфиденциальности | `https://5mb2.ru/static/games/pirate-2048/privacy-policy.html` (или `privacy-policy.html` из архива) |

### Шаг 4. Загрузить графику
1. **Иконка**: `D:\pirat\build\yandex\icons\icon-512.png` (512×512).
2. **Скриншоты** (мин. 2, лучше 4, размер **1280×720**):
   - `D:\pirat\store\shots\yandex-home.png`
   - `D:\pirat\store\shots\yandex-moves.png`
   - `D:\pirat\store\shots\yandex-shop.png`
   - `D:\pirat\store\shots\yandex-shop-skin.png`
3. Превью (видео/анимация 9:16) — опционально, можно пропустить.

### Шаг 5. Настроить лидерборд и облако
1. В настройках игры найти раздел **«Лидерборды»** (или «Таблица рекордов»).
2. Создать лидерборд с именем **`pirat2048_top`** (тип «Баллы», сортировка по убыванию).
   - Имя должно совпадать с кодом: `sdk.getLeaderboards().setLeaderboardScore('pirat2048_top', score)`.
   - Если лидерборд не создать — код безопасно пропустит запись, игра не сломается.

### Шаг 6. Монетизация (реклама)
1. В разделе **«Монетизация»** / «Реклама» включить:
   - **interstitial** (полноэкранная между партиями),
   - **rewarded** (за просмотр — награда в магазине/за ежедневный бонус).
2. Для выплат Яндекс потребует **подключить платёжный аккаунт** (для РФ — самозанятость
   или ИП/ООО). Без него реклама может не показываться даже после модерации.
3. До модерации рекламы методы `showInterstitial`/`showRewarded` возвращают `false` —
   игра работает в обычном режиме без сбоев.

### Шаг 7. Тест в песочнице (обязательно)
1. В кабинете нажать **«Запустить»** / открыть песочницу (игра откроется в тестовом iframe).
2. Проверить (подробный чек-лист — в разделе «Тест в песочнице» ниже).
3. Если всё работает — **«Отправить на модерацию»**.

### Шаг 8. Модерация
- Обычно 1–3 рабочих дня. При отклонении придёт причина — см. «Типичные причины отклонения».
- После одобрения игра появится в поиске/каталоге и начнёт показывать рекламу.

## Тест в песочнице (перед отправкой)

- [ ] Игра запускается, лоадер доходит до 100% (`LoadingAPI.setLoadingProgress`).
- [ ] Экран «Играть»/меню отображается, шрифты не плывут.
- [ ] Новая партия: свайпы/стрелки работают, плитки двигаются.
- [ ] Кнопка **«Магазин»** открывается: вкладки «Бонусы» и «Скины», покупка/выбор скина.
- [ ] Ежедневный бонус открывается, начисление работает.
- [ ] Реклама (если уже разрешена) появляется по триггерам; rewarded — после просмотра.
- [ ] Очки записываются в лидерборд `pirat2048_top` (видно в тесте, если создан).
- [ ] Облачное сохранение: прогресс переживает перезагрузку в другом окне/браузере.
- [ ] Кнопка «На весь экран» не роняет iframe (код игнорирует отказ).
- [ ] Никаких консольных ошибок (F12 в песочнице).

## Особенности / риски

- Игра открывается в **iframe** Яндекса: полноэкранная кнопка не работает —
  код безопасно игнорирует отказ (`requestFullscreen().catch(() => {})`).
- Прогресс сохраняется локально (localStorage) **и** в облако Яндекса
  (`pirat2048`); при конфликте объединяется (`resolveConflict` в `cloud-sync.js`).
- Для рекламы и лидерборда нужна модерация кабинета; до неё — тихий web-режим.
- `sw.js` в сборку включён (PWA), но на площадке не регистрируется.
