# 🏴‍☠️ 2048 - Пиратская версия

Классическая игра 2048 с пиратской тематикой! Объединяйте плитки, достигните 2048 и победите!

## 🎮 Как играть

### Управление
- **Стрелки вверх/вниз/влево/вправо** - движение плиток в соответствующую сторону
- **Кнопка "🔄 Новая игра"** - начать новую игру

### Цель
1. Объедините одинаковые числа, чтобы получить плитку с числом 2048
2. Каждый ход в свободное место появляется новая плитка (90% - число 2, 10% - число 4)
3. Игра заканчивается, когда нет возможных ходов
4. Побеждают при достижении 2048!

### Правила
- Все плитки движутся в одном направлении одновременно
- Когда две плитки с одинаковым числом сталкиваются, они объединяются в одну плитку с суммой
- Каждое объединение добавляет очки в счёт
- Пустая ячейка остаётся пустой, если нет плиток для движения

## 📋 Цвета плиток

| Значение | Цвет | Описание |
|----------|------|---------|
| 2 | Серый | Начальная плитка |
| 4 | Оранжевый | Редкая начальная плитка |
| 8-64 | Оттенки оранжевого | Объединённые плитки |
| 128-512 | Жёлтый | Средние значения |
| 1024-2048 | Золотой | Высокие значения |
| 4096+ | Тёмный золотой | Очень высокие значения |

## 🚀 Запуск

1. Клонируйте репозиторий или откройте `index.html` в браузере
2. Игра загрузится автоматически
3. Начните играть, используя стрелки клавиатуры
4. Нажмите "🔄 Новая игра" для перезагрузки

## 📊 Примеры стратегий

### Новичкам
- Сначала создавайте маленькие объединения (2+2=4)
- Не спешите двигать плитки случайно
- Старайтесь оставлять свободные ячейки

### Опытным игрокам
- Сосредоточьте высокие значения в одном углу
- Используйте одну строку/колонку для основных манипуляций
- Планируйте несколько ходов вперёд

## 🎓 Исходный код

Класс `Game` содержит всю логику:
- Управление сеткой плиток
- Проверка победы/поражения
- Анимация движений
- Расчёт очков
